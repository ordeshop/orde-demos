Bewegung – wie aus einem Keyframe ein Motion-Design-Film wird

  1. Keyframe: zwei Punkte, gleichmäßig verbunden.
  2. Kurve: die Zeit wird ungleich verteilt.
  3. Gewicht: Fallen, Stauchen, Nachfedern, Bewegungsunschärfe.
  4. Raster: jede Form bleibt in ihrer Zelle.
  5. Schrift: das Wort Bewegung im Raster.
  6. Farbe: Farbe als Ereignis.
  7. Render: alles zusammen in Schleife.
