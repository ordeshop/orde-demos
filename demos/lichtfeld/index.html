Szene 02 / 07 — Materie

Kamera z = 9.00

Materie hat Gewicht.

Chrom mit Dünnschicht-Effekt. Die Farben entstehen so wie auf einer Seifenblase: durch Licht, das sich an einer hauchdünnen Schicht überlagert.

Jede Fläche spiegelt ihre Welt.

Physikalisch berechnete Reflexionen. Kein gemaltes Glanzlicht, jede Spiegelung folgt der Kamera.

Glas bricht das Licht.
